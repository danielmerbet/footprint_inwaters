For the [[climoscilakes-paper-plan]] manuscript the user dislikes "organize/organise" when relating climate oscillations (ENSO/IOD/NAO) to teleconnected lakes and rivers. Agreed hybrid (2026-07-14):
- **"explain" / "account for"** where the object is a fraction/percentage of variance (it is literally what adj-R² measures) — e.g. "the modes explain a median 25–30% of interannual variance".
- **"influence"** for the qualitative relationship — e.g. "where an oscillation influences a river".
- Leave "organize" only where it means something else: a mode "organising regional climate" (idiomatic), or "the organising axis" (= governing axis).

**Why:** "organize a % of variance" is imprecise and reads as jargon; the user wants clearer, physically-honest verbs. Causal direction (ocean→atmosphere→water) is unambiguous, so "influence" doesn't overclaim.
**How to apply:** default to this verb choice in the manuscript prose and any future aquatic-sentinels writing; don't blanket find-replace — check whether the object is "% of variance" (→ explain) vs a water body (→ influence).
